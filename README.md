# Facundo Sosa Bianciotto — Portfolio

Portfolio completo basado en la estructura y contenido originales, con una capa visual hacker/terminal en negro + verde.

## Se conserva del original
- Navbar: About me / Projects / Skills / Contact
- Hero de dos columnas: nombre + rol a la izquierda, Lottie a la derecha
- About con los 5 párrafos originales
- Projects en filas grandes alternadas
- Todos los proyectos, descripciones, enlaces e iconos originales
- Skills con Core Skills + Technologies
- Contact y lógica EmailJS
- Footer y theme toggle

## React Bits integrado
- Pixel Blast solo en el hero (`patternDensity={0.6}`)
- ASCII Text para el nombre (`enableWaves={false}`)
- Border Glow en cards/paneles
- Specular Button en acciones

Los screenshots de proyectos y logos de tecnologías nunca reciben filtros verdes.

## Ejecutar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
